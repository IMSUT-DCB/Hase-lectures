胸腺でT細胞はどのように選ばれる？

T細胞は胸腺で分化し、自己MHCを適切に認識できるか、自己抗原に強く反応しすぎないかをチェックされます。

DN → DP → SP

カードを選ぶか「次へ」で3段階を確認しましょう。

正の選択：認識できる細胞が生存

主に胸腺皮質で行われる。

自己ペプチド–自己MHCを適切に認識できるT細胞が生存

  • MHCクラスIを認識する細胞はCD8+ T細胞へ
  • MHCクラスIIを認識する細胞はCD4+ T細胞へ

負の選択：強く反応するクローンを除去

主に胸腺髄質で行われる。

自己抗原に強く反応するT細胞クローンが除去される

AIREが組織特異的自己抗原の提示に重要。

ヌードマウスやディジョージ症候群では胸腺異常によりT細胞の減少・欠損がみられる。

ナイーブT細胞の活性化に必要な3つのシグナル

シグナルのカードを選ぶと詳細を表示します。

シグナルの組み合わせと活性化

  • シグナル1だけでは十分な活性化は起こらず、アネルギーとなる
  • シグナル1＋2でナイーブT細胞が活性化する
  • シグナル3がCD4+ T細胞の分化方向を決める
  • 活性化T細胞はIL-2を産生し、増殖・分化する

樹状細胞の成熟

PAMPsをTLRなどで認識 → CCR7発現が上昇 → リンパ節へ移動 → MHCと共刺激分子の発現が上昇 → ナイーブT細胞を活性化する
